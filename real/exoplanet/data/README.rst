Radial-velocity data
====================

The rvs_000*.txt files are the dataset used by the juliet RV benchmark.
parameters0.txt through parameters3.txt define the 0/1/2/3-planet cases.

The HATS-46 transit benchmark is kept separate from these files: its public
TESS Sector 2 FITS light curve is downloaded on first run by transient.py.
The source URL is the one used by the juliet transit tutorial.
